# Sprint__7

В рамках проекта Sprint_7 проведено автоматизированное тестирование API учебного сервиса Яндекс.Самокат.

Подготовительный этап:
Создан Maven-проект на Java 11.
Подключены библиотеки JUnit 4, RestAssured и Allure.
Выполнено ручное тестирование всех ручек через Postman для понимания логики работы API.

Написаны автотесты на следующие ручки:
Создание курьера — проверено успешное создание, ошибка при создании дубликата, обязательность полей (логин и пароль), корректность кодов ответа и поля ok: true.
Логин курьера — проверена успешная авторизация с получением id, ошибки при неверном логине/пароле, при отсутствии обязательных полей и при авторизации несуществующего пользователя.
Создание заказа — с помощью параметризации проверены все варианты указания цвета (BLACK, GREY, оба цвета, без цвета). Во всех случаях заказ создаётся, в ответе приходит track.
Список заказов — проверено, что запрос возвращает код 200 и тело ответа содержит список заказов.

Технические требования:
Для каждого шага теста использована аннотация @Step.
Все тесты независимы — тестовые данные создаются перед тестом и удаляются после его выполнения.
Хардкод отсутствует — данные генерируются динамически.
Сделан и закоммичен отчёт Allure.
